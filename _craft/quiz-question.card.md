# Card — quiz-question
Applies to every unit in the bank — one 1–2 sentence second-person situation plus exactly four terse declarative options — run before the unit is committed to `questions.ts`.

## Tests
- Delete-the-sentence: remove any sentence of the prompt — does the remaining prompt still pose the same choice? If yes, that sentence advanced nothing; cut it.
- Downstream-state test: can you name a different downstream state for each of the four options, in a different phrase each time? If two share one, cut or merge — two options with the same consequence are one option wearing two coats.
- Sentence-length test: read the four options aloud — do at least two differ in length and shape? If all four scan identically, vary one.
- Announced-fails test: does an option name a virtue, a code, or a competence rather than enacting it? If yes, delete the naming and write the act alone.
- Trait-name test: can a reader state the trait the option scores for using only the option's own words? If yes, the option is answering the quiz for them — rewrite it as the act alone, and let the axis do the scoring.
- Want-at-risk handback: does the prompt stop before the outcome, with the wanted thing still in doubt? If the situation has already resolved and the options only react to it, cut earlier.
- Cost-free-yes test: before writing an option, name what it costs the taker in one phrase — if you cannot, that option is the obviously-correct one and the question is dead.
- Displacement test: does an abstract noun (loyalty, resentment, duty, integrity, ambition, betrayal) appear in the prompt? If so the answer key is in the question — displace it onto the concrete situation and delete the noun.
- Present-situation test: is this a situation happening now, or a biography of the taker? A résumé of attributes ("you have always been the one who…") fails; the taker arrives through a present situation and a want.
- One-telling-particular test: does the prompt carry exactly one load-bearing detail (the six years, the sixteen hours), or a catalogue? Keep the one that carries a judgment; cut the rest.
- Filter-word sweep: search the prompt and options for "you see / you notice / you feel / you realise" — delete the filter and present the thing directly.
- Intensifier test: strip every intensifier and adjective of degree (really, deeply, utterly, absolutely, very) — if the situation weakens, it was never loaded; find a harder particular instead.
- Second-person test: would the prompt read identically in third person? Then "you" is decorative — rebuild it around what the taker is doing or about to do.
- Fandom test: does any word in the prompt or an option only make sense to a fan? Zero fandom in the questions; all of it lives in the results.
- Legibility test: could a reader who has never seen the source material answer this unit truthfully? A situation only fans can parse is fandom trivia in a mundane costume.

## Kill list
- Trait names inside an option: leader, loyal, ruthless, cautious, rebel, ambitious, brave, principled, reckless, selfless
- Announced virtue, code, or competence ("I don't leave people behind — that's who I am")
- Abstract nouns in the prompt naming the question's own subject
- Hedges and modals in an option: try to, probably, maybe, perhaps, sort of, I guess, hopefully
- One option markedly longer than its three siblings
- The obviously-correct option; any option that costs the taker nothing
- Two options that land the taker in the same downstream state
- A prompt that glosses what the situation means about the taker
- Filter-word openers ("you notice that," "you feel")
- Intensifier-dressed stakes; world-by-adjective
- Biography before situation; the character sheet recited back at the taker
- Decorative second person
- Fandom proper nouns anywhere in prompt or options
- A rhetorical template repeated across consecutive units ("What do you do?" ×12)
- More or fewer than four options

## Micro-examples
Before: "Your loyalty to the team is tested when your manager asks you to cover for a mistake."
After: "Your manager asks you to sign off on numbers you did not check."

Before: "You have always been a cautious, methodical person, and now you must decide."
After: "The plan is three days old and two of its assumptions died this morning."

Before: "- Be brave and confront them directly about it."
After: "- Say it to their face, in the meeting."

Before: "- Probably try to talk to someone about it first."
After: "- Ask the one person who'd tell me I'm wrong."

Before: "- Refuse." / "- Say no."
After: "- Refuse, in writing, with your name on it." / "- Leave. Not loudly. Just stop being available."

Before: "You've been at the emergency for sixteen hours, which is longer than anyone expected, and you're exhausted but you notice you're still there, which says something about you."
After: "Sixteen hours into the emergency. What's actually keeping you there?"
